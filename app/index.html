✨ 核心功能

强大的功能特性

基于先进的算法和百度地图API，提供全方位的社区生活圈分析

🕐

等时圈计算

基于百度地图步行路径规划API，通过扇形采样+二分搜索算法， 计算真实路网下的5/10/15分钟步行可达范围。

🛣️

Graph路网可视化

构建路网图结构，按道路实际形状渲染路线， 标注每段距离和时间，直观展示步行路径。

📍

POI设施分析

检索圈内医疗、教育、购物、养老、文体、餐饮等各类民生设施分布， 评估设施覆盖情况。

⚠️

盲区识别

自动标注周边1公里内缺乏关键设施的"灰色区域"， 帮助识别服务盲区。

📊

体检报告

生成雷达图、热力图、柱状图等可视化报告， 全面评估社区生活圈质量。

🔄

多社区对比

支持多个社区对比分析，帮助选择最佳居住位置， 提升生活质量。

🚀 快速开始

几分钟内启动项目

按照以下步骤，快速启动并体验15分钟生活圈分析助手

1

克隆项目

从Gitee克隆项目到本地

# 克隆项目
git clone https://gitee.com/wuxiejiameng123/15min-life-circle.git
cd 15min-life-circle
2

配置环境

申请百度地图API Key并配置环境变量

# 复制环境变量模板
cp .env.example .env

# 编辑.env文件，填入百度地图API Key
BAIDU_MAP_AK=你的API密钥
3

启动服务

使用Docker Compose一键启动所有服务

# 启动所有服务
docker-compose up -d

# 访问应用
# 前端: http://localhost:3000
# 后端: http://localhost:8080
4

开始使用

选择社区或自定义位置，点击"开始体检"按钮

# 功能说明
1. 选择预设社区或输入自定义坐标
2. 点击"开始体检"按钮
3. 查看等时圈、POI设施、盲区分析
4. 导出PDF报告

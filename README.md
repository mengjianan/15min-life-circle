# 15分钟生活圈智能体检与规划助手

基于百度地图开放能力，计算真实路网下的15分钟步行等时圈，分析社区民生设施覆盖情况，自动识别服务盲区，输出可视化体检报告。

## 功能特性

- 等时圈计算：基于百度地图步行路径规划API，通过扇形采样+二分搜索算法，计算真实路网下的15分钟步行可达范围
- Graph路网可视化：构建路网图结构，按道路实际形状渲染路线
- POI设施分析：检索圈内医疗、教育、购物、养老等各类民生设施分布
- 盲区识别：自动标注周边1公里内缺乏关键设施的区域
- 体检报告：生成雷达图、热力图、柱状图等可视化报告
- 风水检测：分析地形、水系、环境、方位等因素，生成风水评分

## 快速部署

### 前置条件

- Docker 20.0+
- Docker Compose 2.0+
- 百度地图API AK

### 一键部署

1. 克隆仓库
2. 配置环境变量：cp .env.example .env
3. 编辑 .env 文件，填入百度地图AK
4. 启动服务：docker-compose up -d
5. 访问前端：http://localhost:3001（端口 3001，体检等接口经 nginx 同源代理到后端）

## 防滥用与容错（评审说明）

### 自定义选点密码
- 「自定义位置」与地图上的「点击地图选择位置」需输入密码：`15min2026`
- 通过后本次浏览器会话不再询问；四个预设社区不受限制
- 目的：开源部署后防止任意坐标反复调用地图 API（地理编码 / POI 检索 / 路径规划）刷爆配额
- 密码存放于 `frontend/src/config.ts` 的 `CUSTOM_POINT_PASSWORD`，部署方按需自行修改后重新构建

### 预设社区缓存快照
- 四个预设街道（湖南路 / 中央门 / 新街口 / 夫子庙）的完整体检结果内置在 `frontend/public/snapshots/`
- 等时圈、POI 检索等任一地图 API 调用失败时，前端自动降级展示对应快照，页面内容正常显示（顶部横幅提示已展示缓存数据，可重试）
- 快照为真实体检结果快照，随构建产物一同分发，断网 / 限流 / 后端不可达时演示不空白

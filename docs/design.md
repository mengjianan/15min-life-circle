## 2. 核心算法设计

### 2.1 等时圈计算算法

#### 算法概述

采用**扇形采样 + 二分搜索**算法，在不获取底层路网数据的前提下，通过调用百度地图步行路径规划API，推导出15分钟步行等时圈。

#### 算法步骤

```
输入：中心点坐标 C(lng, lat)，最大步行时间 T=15min
输出：等时圈多边形 P

1. 初始化方向集合 D = {0°, 10°, 20°, ..., 350°}  // 36个方向
2. 对每个方向 d ∈ D：
   a. low = 0, high = MAX_RADIUS (2000m)
   b. 重复 BINARY_SEARCH_ITERATIONS (8) 次：
      - mid = (low + high) / 2
      - 计算目标点 T = destination(C, d, mid)
      - 调用API获取步行时间 t = walking_time(C, T)
      - 如果 t < T: low = mid, best_point = T
      - 否则: high = mid
   c. 记录该方向的边界点 best_point
3. 连接所有边界点，生成平滑多边形 P
4. 返回 P
```

#### 复杂度分析

- 时间复杂度：O(D × B × API)，其中 D=36(方向数)，B=8(二分迭代次数)
- API调用次数：36 × 8 = 288次（可通过并发优化到约60次/秒）

### 2.2 空间插值算法

为使等时圈边界更平滑，对离散采样点进行样条插值：

```python
def interpolate_boundary(boundary_points, num_interpolated=100):
    """
    对边界点进行样条插值
    
    Args:
        boundary_points: 原始边界点列表
        num_interpolated: 插值后的点数
    
    Returns:
        插值后的边界点列表
    """
    from scipy.interpolate import CubicSpline
    
    # 提取坐标
    lngs = [p.lng for p in boundary_points]
    lats = [p.lat for p in boundary_points]
    
    # 添加首尾相连
    lngs.append(lngs[0])
    lats.append(lats[0])
    
    # 参数化
    t = np.linspace(0, 1, len(lngs))
    t_new = np.linspace(0, 1, num_interpolated)
    
    # 三次样条插值
    cs_lng = CubicSpline(t, lngs)
    cs_lat = CubicSpline(t, lats)
    
    lngs_interp = cs_lng(t_new)
    lats_interp = cs_lat(t_new)
    
    return [GeoPoint(lng, lat) for lng, lat in zip(lngs_interp, lats_interp)]
```

### 2.3 Graph路网构建算法

#### 数据结构

```python
class RoadGraph:

    def __init__(self):
        self.graph = nx.DiGraph()  # 有向图
        # 节点：(lng, lat) 元组
        # 边属性：distance, duration, road_name, points
```

#### 构建流程

```
输入：路径规划结果 route_data
输出：路网图 G

1. 解析路径中的所有步骤 steps
2. 对每个 step：
   a. 解析路径点字符串 → 坐标列表 points
   b. 计算每个小段的距离和时间（按比例分配）
   c. 将相邻点作为边添加到图中
3. 合并重叠边（取平均权重）
4. 返回图 G
```

### 2.4 盲区识别算法

#### 算法概述

通过在等时圈内生成网格点，检查每个点周边的设施覆盖情况，识别服务盲区。

#### 算法步骤

```
输入：等时圈多边形 P，POI数据集 F
输出：盲区列表 B

1. 在多边形 P 内生成网格点 G（间距100m）
2. 对每个网格点 g ∈ G：
   a. 对每个设施类别 c：
      - 统计 g 周边1km内类别c的设施数量 n
      - 如果 n < MIN_COUNT (1): 标记为盲区点
3. 聚类相邻的盲区点 → 生成盲区区域
4. 返回盲区列表 B
```

## 4. 性能优化策略

### 4.1 API调用优化

1. **并发控制**：使用信号量限制并发请求数（默认5）
2. **请求缓存**：相同坐标和参数的请求结果缓存24小时
3. **批量请求**：使用百度地图批量距离矩阵API
4. **降级策略**：API失败时使用直线距离估算

### 4.2 前端渲染优化

1. **图层分离**：等时圈、路网、POI分别在不同图层
2. **按需加载**：只加载当前视口范围内的数据
3. **防抖处理**：用户交互时延迟触发计算
4. **Web Worker**：复杂计算放到Worker线程

### 4.3 数据缓存策略

1. **内存缓存**：热点数据缓存在内存中
2. **SQLite缓存**：持久化缓存计算结果
3. **过期机制**：缓存数据24小时后自动失效

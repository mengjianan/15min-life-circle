**15分钟生活圈智能体检与规划助手**
- 基于百度地图开放能力，计算真实路网下的 5/10/15 分钟步行等时圈

## 核心功能
1. **等时圈计算**：扇形 24 方向采样 + 二分搜索，真实路网可达范围；支持 5/10/15 分钟（300/600/900 秒）
2. **出行方式**：步行 / 骑行 / 公共交通（公交、地铁两行独立规划）/ 驾车
3. **POI 设施分析**：医疗、教育、购物、养老、文体、餐饮、交通 7 类
4. **盲区检测**：空间盲区（有坐标，地图红圈）/ 可达性盲区（按类别数量，报告展示）
5. **真实路线显示**：中心到设施按出行方式切换真实路线（前端 JS SDK 客户端算，零后端配额，30 天本地缓存）
6. **综合评分**：设施覆盖 35% + 可达性 25% + 出行适配 20% + 盲区 10% + 风水 10%
7. **风水评分**：七项加权（水系 20% 最高，地势/朝向/道路形态/敏感设施各 15%，绿化/人气各 10%）
8. **体检报告**：左右两页 A4 版式（cr- 前缀样式），含五维雷达、分组条形图（recharts）
9. **悬浮设施卡片**：步行/骑行/公交/地铁/驾车分列耗时（门到门口径），按等时圈可达性过滤

## 关键技术事实
- **等时圈公共交通 = 车程近似**：`isochrone_engine.py` 速度≥4m/s 走 driving 矩阵；圈边缘设施公交耗时超15分钟是口径差，非计算错误
- **悬浮卡耗时 = 门到门**：`plan.getDuration()` 含两端步行+换乘+估算等车+车内时间
- **CSS 架构**：main.tsx 导入顺序 index.css → three-column.css → report-styles.css → header-styles.css → comprehensive-report.css → mode-score-panel.css → score-overview.css，后者覆盖前者
- **BMap 坑**：`new BMap.Map(el)` 只在初始化取一次容器尺寸，变了要 `checkResize()`（已接 ResizeObserver）；`BMap.Geocoder` 逆地理可能不回调，需超时兜底
- **社区命名格式**：`区县+道路+街道`（如 鼓楼区湖南路街道），与 SAMPLE_COMMUNITIES 一致

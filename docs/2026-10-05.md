**15分钟生活圈智能体检与规划助手**

### 等时圈去棱角——接线三次样条插值（用户：等时圈有棱角，要光滑曲线）
- **诊断（用户先问原因）**：① 采样方向只有 16 个（config `ISOCHRONE_DIRECTIONS=16`），16 边形全是棱角；② `core/interpolator.py` 的三次样条插值是**死代码，全项目零调用**（文档宣称的「样条插值」从未生效）；③ 前端 BMap.Polygon 按顶点直线连接
- **方案（用户确认：要光滑曲线，不要多边形观感）**：后端样条加密 + 方向数 16→36，前端不动（点够密目视即曲线）
- **后端改动**：
  - `config.py`：`ISOCHRONE_DIRECTIONS` 16 → **36**（routematrix 单次 ≤64 终点，36 安全）
  - `interpolator.py` `interpolate_boundary` 重写：`bc_type="periodic"` **闭合周期样条**（原实现默认样条，首尾接缝留折角）；去相邻重复点、`t[-1]=1.0` 防浮点、`endpoint=False` 不输出重复闭合点、周长为 0 早退
  - `isochrone_engine.py` 新增 `_smooth_boundary()`：**循环滑动平均**（压二分搜索 ~30m 量化抖动，不压的话样条忠实跟随噪声出毛刺）→ 周期样条加密到 `max(96, 采样数×4)`（36→144 点）→ 6 位小数 → shapely `is_valid` **自交保护**（半径剧烈抖动时过冲则退回原始环）；mock 等时圈同样走加密；缓存 key 加 `"s2"` 版本号作废旧棱角环缓存
  - `api/graph.py` `/isochrone-graph`：加密后上百个边界点逐个请求路线会打出上百次 API → 抽样封顶 24 个方向
- **测试更新**：`test_isochrone.py` 5 处 `len == directions` 断言改为 `>= 96`（新契约）
- **验证**：

### 悬浮卡片避让路线（用户：卡片有时挡住路线线条，先要方案）

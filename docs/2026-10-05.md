## 项目概述
**15分钟生活圈智能体检与规划助手**
- 基于百度地图开放能力，计算真实路网下的 5/10/15 分钟步行等时圈
- 分析社区民生设施覆盖，自动识别服务盲区，输出可视化体检报告（含风水评分）
- 前端：React 18 + TypeScript + Vite 5；后端：FastAPI (Python)
- 部署：GitHub Pages（根目录解析：`/` 是介绍首页、`/app/` 是应用）

## 关键技术事实
- **AK 脱敏链路**：`frontend/index.html` 用 `%VITE_BAIDU_MAP_AK%` 占位符，Vite 构建时替换；真实值只在 `frontend/.env` / 根 `.env`（gitignore 覆盖）；Docker 经 `ARG/ENV` + compose `build.args` 注入
- **API_BASE_URL 分流**：`*.github.io` → 直连 `http://100.126.142.87:8081/api`（历史可用路径），其余 → 同源 `/api`
- **预设社区快照降级**：`frontend/public/snapshots/{hunanlu,zhongyangmen,xinjiekou,fuzimiao}.json`（618~706KB/份），接口失败时前端 fetch 快照，**与真实调用走同一条进度动画流程，不弹降级横幅**
- **PDF 导出**：`exportElementPDF` 克隆真实 DOM + SVG→data-URL img → html2canvas → jsPDF A4 分页
- **自定义选点密码**：`CUSTOM_POINT_PASSWORD`（值见作品介绍文档/提交邮件，README 只留提示）；sessionStorage 会话免验
- **社区对比**：IndexedDB 3 条全量 fullResult，下拉条 UI 与报告一致
- 等时圈：36 向扇形采样 + 二分搜索 + 三次样条插值；评分权重 设施35/可达25/出行20/盲区10/风水10

# 技术设计文档

## 1. 地图API调用策略

### 1.1 API选择

使用百度地图Web API和JS API：

- **地点检索API**：搜索周边POI设施
- **路线规划API**：计算步行/骑行/公交/驾车路线
- **地理编码API**：地址与坐标互转
- **天气查询API**：获取天气数据

### 1.2 调用优化

- **缓存策略**：相同查询结果缓存24小时
- **批量处理**：并发请求多个API
- **限流降级**：超出配额时使用模拟数据

## 2. 等时圈生成算法

### 2.1 扇形采样

将360度分为24个方向（每15度一个），在每个方向上搜索可达边界。

### 2.2 二分搜索

对每个方向，使用二分搜索找到给定时间内的最远可达点：

1. 设置搜索范围 [0, max_radius]
2. 取中点，计算到中点的路线时间
3. 根据时间调整搜索范围
4. 重复直到收敛

### 2.3 边界平滑

将采样点连接成多边形，使用样条插值平滑边界。

## 3. POI数据清洗策略

### 3.1 数据去重

- 按名称和地址去重
- 保留距离中心最近的记录

### 3.2 分类标准化

将不同来源的POI统一分类到6大类：
- 医疗、教育、购物、养老、文体、餐饮

### 3.3 距离过滤

只保留等时圈内的设施。

## 4. 盲区识别算法

### 4.1 网格划分

将分析区域划分为100x100米的网格。

### 4.2 覆盖计算

对每个网格，检查是否有对应类型的设施在1公里范围内。

### 4.3 盲区标注

将缺乏关键设施的连续网格合并为盲区。

## 5. 风水检测算法

### 5.1 地形分析

- 高程数据：采样多个点计算平均高程
- 坡度计算：根据高程差计算坡度

### 5.2 水系分析

- 搜索周边河流、湖泊
- 计算水体距离和方位
- 判断水势形态（环抱水/反弓水）

### 5.3 环境分析

- 有利设施：公园、学校、图书馆
- 不利设施：医院、殡仪馆、垃圾站

### 5.4 方位分析

基于八宅理论判断方位吉凶。

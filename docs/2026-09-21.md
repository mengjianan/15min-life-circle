## 核心功能

### 1. 社区体检分析
- 支持选择社区或自定义位置
- 计算5/10/15分钟等时圈
- 分析周边设施覆盖（医疗、教育、购物、养老、文体、餐饮、交通）

### 2. 多出行方式支持
- 步行（速度：1.2m/s）
- 骑行（速度：3.5m/s）
- 公交（速度：5m/s）
- 驾车（速度：8m/s）

### 3. 综合评分体系
- 设施覆盖（35%权重）
- 可达性（25%权重）
- 出行适配（20%权重）
- 盲区识别（10%权重）
- 风水评分（10%权重）

### 4. 时间维度切换
- 5分钟（300秒）
- 10分钟（600秒）
- 15分钟（900秒）

### 5. 盲区检测优化
- 使用距离计算替代API调用
- 从20,736次API调用减少到16次
- 使用haversine公式计算距离

### 6. 风水评分
- 地势评分
- 朝向评分
- 水系评分
- 绿化评分

## 今日改动（2026-09-21）

### 1. 地图路线显示功能
- 在 MapView 组件中添加了路线显示功能
- 路线数据从 `/api/graph/route` 接口获取
- 支持8个方向的路线显示
- 路线颜色自动分配，便于区分
- 添加了路线显示/隐藏控制按钮

### 2. 风水数据地图显示
- 在 MapView 组件中添加了风水数据可视化
- 显示水系信息（蓝色水滴图标）
- 显示地形信息（绿色山峰图标）
- 显示朝向分析（黄色指南针图标）
- 点击图标可查看详细信息
- 添加了风水显示/隐藏控制按钮

### 3. 等时圈速度系数优化
- 更新了骑行、公交、驾车的 speed_multiplier 值
- 骑行: 1.8 → 2.9
- 公交: 2.2 → 4.2
- 驾车: 2.8 → 6.7
- 等时圈大小现在更符合实际情况

### 4. 百度地图API配置
- 更新了 .env 文件中的 BAIDU_MAP_AK
- API 现在可以正常返回真实数据
- 部分 POI 查询仍会返回模拟数据（API 无结果时）

### 5. 布局重构
- 删除旧组件：时间维度对比（旧版）、关键指标、各类评分、出行方式覆盖对比
- 添加紧凑版时间维度对比（放在综合评分上方）
- 综合评分、出行方式对比、体检总结改为纵向排列

### 6. 样式优化
- 统一中文字体大小为12px
- 综合评分明细添加条形图
- 减少图标和文字间距
- 条形图宽度与分数值一致

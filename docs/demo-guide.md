# 🎬 演示视频准备指南

## 视频时长
建议 **3-5分钟**，突出项目亮点

## 录制内容大纲

### 1. 开场介绍 (30秒)
- 项目名称：15分钟生活圈智能体检与规划助手
- 核心理念：基于Graph数据结构和地图可视化
- 技术栈：React + FastAPI + 百度地图API + NetworkX

### 2. 功能演示 (2-3分钟)

#### 2.1 选择社区
- 展示社区下拉列表
- 演示自定义位置功能

#### 2.2 开始体检
- 点击"开始体检"按钮
- 展示加载动画

#### 2.3 等时圈可视化
- 展示5/10/15分钟步行范围
- 切换时间维度
- 展示面积对比图

#### 2.4 Graph路网展示
- 开启Graph图层
- 展示路线沿实际道路形状
- 点击路线查看距离和时间

#### 2.5 POI设施覆盖
- 开启POI图层
- 展示各类设施标记
- 点击查看设施详情

#### 2.6 盲区检测
- 开启盲区图层
- 展示服务盲区热力图

#### 2.7 分析报告
- 展示综合评分
- 展示各类设施评分
- 展示改善建议

#### 2.8 社区对比
- 分析多个社区
- 展示对比图表

#### 2.9 导出报告
- 演示PDF导出功能

### 3. 技术亮点 (30秒)
- Graph数据结构
- 并发计算优化
- 双层缓存策略

### 4. 结尾 (15秒)
- 项目链接
- 未来规划

## 录制工具推荐

### Windows
- **OBS Studio** (免费，功能强大)
- **Windows Game Bar** (Win+G快捷键)

### 在线工具
- **Loom** (在线录制，方便分享)
- **Screencastify** (Chrome扩展)

## 录制技巧

1. **提前演练**
   - 先熟悉所有功能
   - 准备好要说的内容

2. **保持简洁**
   - 每个功能演示15-30秒
   - 避免冗长的操作

3. **突出亮点**
   - Graph路网可视化
   - 真实道路形状
   - 并发计算优化

4. **添加字幕**
   - 为关键功能添加说明文字
   - 方便评委理解

5. **背景音乐**
   - 轻柔的背景音乐
   - 音量不要太大

## 视频格式要求

根据比赛要求：
- 格式：MP4
- 分辨率：1080p或720p
- 时长：3-5分钟
- 文件大小：控制在100MB以内
